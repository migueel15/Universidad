# Entorno de la práctica P2

Desde este directorio, activa el entorno y ejecuta el programa inicial:

```bash
source .venv/bin/activate
python initial_solution.py
```

Para recrear el entorno con Python 3.14:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Ejecuta el programa desde este directorio para que encuentre `bikes.csv`. El enunciado indica los pasos y los archivos de entrega; las cifras pueden variar entre versiones de las bibliotecas. Para salir del entorno, ejecuta `deactivate`.
