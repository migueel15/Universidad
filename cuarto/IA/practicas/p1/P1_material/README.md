# Practice P1, quick start

## Files in this package

- `initial_solution.py`, the program to complete.
- `creditcard_subset.csv`, the data, 32,768 transactions.

## Requirements

Python 3.10 or later, and two libraries:

    $ python3 --version
    $ pip install --user pandas scikit-learn

## Running

    $ python3 initial_solution.py

## Where the data comes from

The first 32,768 records of the Credit Card Fraud Detection dataset published
by the Machine Learning Group of the Universite Libre de Bruxelles, in their
original order, so the same rows can be rebuilt from the full file. The full
version, with 284,807 records, is at
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud and needs a free
account. This practice does not need it.

Attribution: Andrea Dal Pozzolo, Olivier Caelen, Reid A. Johnson and Gianluca
Bontempi. Calibrating Probability with Undersampling for Unbalanced
Classification. IEEE Symposium on Computational Intelligence and Data Mining,
2015.
